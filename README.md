## How the repository works

- **One `index.md` per directory** provides a readable GitHub entry point and keeps the directory tracked even when there are no topic notes yet.
- **Topic notes** capture a problem, mental model, key relationships, practical examples, and common failure modes.
- **Hands-on exercises** live near the topic they reinforce; reusable project narratives live under `projects/`.
- **Execution and milestones** live in Trello, while the conceptual roadmap and knowledge live here.
