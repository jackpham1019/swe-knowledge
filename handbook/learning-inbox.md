# Learning Inbox Workflow

The inbox is a **temporary capture area** for snippets, questions, examples, and explanations that may deserve permanent reference notes. It is not a backlog and not an archive.

## Two-device capture strategy

Keep `potential-inbox.md` and `potential-inbox-lenovo.md` as **separate local capture files** while working on different laptops. This avoids simultaneous edits and sync conflicts. Do not merge them merely for organizational purity. Both feed the same review process.

1. Capture quickly in the file belonging to the current laptop.
2. During review, check existing topic notes and verify accuracy.
3. Incorporate all useful detail into focused, descriptive topic files; create new ones if needed.
4. Add contextual links only where they improve navigation.
5. Delete processed capture items after verifying the destination notes. No catch-all archive.

Keep Trello for actionable tasks and learning milestones. Obsidian is the detailed reference. Long explanations and code examples are welcome when they help future retrieval.
