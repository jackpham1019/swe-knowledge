# Software Engineering Goals

## Long-term direction

Become a well-rounded software engineer capable of independently designing, implementing, debugging, and maintaining production software.

Develop strong foundations in software engineering while continuously adapting to new technologies and engineering practices.
## Active goals

### Goal 1 — [Become productive in the .NET Ecosystem] 

- **Why it matters:** Adapt my existing backend engineering knowledge to C# and .NET for professional software development.

- **Evidence of success:** 
	- Understand C# and ASP.NET Core fundamentals.
	- Independently build and debug backend services.
	- Apply database access, authentication, testing, and dependency injection.
	- Navigate and contribute to an existing .NET codebase.

### Goal 2 — [Become productive with Angular]

- **Why it matters:** Develop the frontend skills needed to contribute to a full-stack engineering team.

- **Evidence of success:** 
	- Understand Angular architecture and core concepts.
	- Build components, services, forms, and routes.
	- Integrate Angular with backend APIs.
	- Independently debug common frontend issues.

### Goal 3 — [Adapt to Professional Engineering Workflows]

- **Why it matters:** Become an effective contributor within an established development team.

- **Evidence of success:** 
	- Understand Git branching, pull requests, and code review practices.
	- Work confidently with GitHub Actions and CI/CD pipelines.
	- Understand common development, testing, and deployment environments.
	- Participate effectively in team planning and technical discussions.

## Future Goals

- Deepen distributed systems and software architecture knowledge.
- Develop advanced cloud-native engineering capabilities.
- Explore AI engineering and related applications.
