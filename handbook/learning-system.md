# Learning System

## Objective

Develop the ability to **recall, connect, reason about, and apply** software engineering knowledge.

## Tools and responsibilities

| Tool               | Responsibility                                                   |
| ------------------ | ---------------------------------------------------------------- |
| Anki               | Spaced recall of mechanisms, problems, and engineering decisions |
| Obsidian           | Knowledge notes, conceptual maps, relationships, and diagrams    |
| Git / GitHub       | Version history and synchronization of Markdown files            |
| Practical projects | Validate understanding through implementation and debugging      |

## Learning workflow

1. **Identify a problem.** What am I trying to understand or solve?
2. **Build a mental model.** Note the major concepts and connections.
3. **Extract recall prompts.** Create only useful, focused Anki cards.
4. **Test integration.** Reconstruct or trace a diagram; change an assumption.
5. **Apply it.** Build, troubleshoot, or explain a real example.
6. **Capture gaps.** Update notes or cards based on what I missed.

## Reviewing

- **Daily:** Anki, within a manageable time budget.
- **Weekly:** Reconstruct one diagram and solve one integrated scenario.
- **Periodically:** Revisit a topic without notes and check whether I can apply it.

## When I get stuck

| Symptom | Response |
| --- | --- |
| Forgot a fact or mechanism | Improve a targeted Anki card |
| Know the parts but not their relationships | Draw or reconstruct a diagram |
| Cannot predict system behavior | Trace a scenario or failure |
| Can explain but cannot implement | Build a minimal working example |

## Principles

- Prefer connected understanding over exhaustive fact collection.
- Keep recall prompts narrow; do not memorize entire notes.
- Use diagrams to explain relationships, not just decorate notes.
- Let practical problems determine what to study next.
- Keep the system lightweight enough to sustain.

## Questions to revisit

- Which activities actually improve my problem-solving?
- Am I adding more notes than I use?
- Which topics can I explain but still cannot implement?
